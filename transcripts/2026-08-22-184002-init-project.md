● One finding worth surfacing before I write the plan — it changes what I'd
  scaffold.

  Spring Boot 3.5.16 is the last free OSS release of the 3.5 line. Free OSS
  support for 3.5 ended 30 June 2026; 3.5.16 shipped 25 June 2026 as the final
  community patch. Everything after that (including security patches) is
  commercial-only. start.spring.io no longer even offers 3.5.x — it only lists
  4.0.8, 4.1.1, and 4.2.0-M1.

  That doesn't make 3.5.16 a bad choice — it's stable, and Java 21 + your whole
  stack works fine on it. But for a project starting today it means no free CVE
  patches from day one.

  Five things I hit and fixed

     silently broken linting.

     derives the server URL from whatever host fetched the spec, so a committed
     artifact would differ depending on where it was generated. Pinned the
     server to / in OpenApiConfig.

     so I marked SystemInfo fields REQUIRED — the frontend now gets name: 
     string, not name?: string.

     removed it once I confirmed the generated output imports nothing from it.
